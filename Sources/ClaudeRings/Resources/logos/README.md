# 서비스 로고 에셋

파일명은 `ServiceID.rawValue`와 같다(`claude.png` → `ServiceID.claude`). 새 서비스를 추가하면
`<service-id>.png`를 여기 추가한다. 없으면 중립 대체 도형(`FallbackGlyph`)이 대신 쓰인다.

## claude.png

- 출처: `https://claude.ai/images/claude_app_icon.png` (Anthropic이 claude.ai에 공개
  제공하는 앱 아이콘, 338×338 PNG, 크림색 둥근 사각형 배경 위 주황색 방사형 마크)
- 가져온 날짜: 2026-09-21
- 처리: 원본은 마크가 불투명한 크림색 배경 위에 있어 그대로 쓸 수 없었다(우리는 마크를
  단계별 색으로 직접 칠해야 함). 배경(크림)과 마크(주황) 기준색을 안쪽 지점에서 뽑아
  각 픽셀이 어느 쪽에 더 가까운지로 알파를 다시 만들고(원본 알파가 낮은 가장자리
  화소는 신뢰할 수 없어 그대로 투명 처리), 마크의 바운딩 박스만 여백을 두고 정사각형
  으로 잘랐다. 그 결과 **마크의 실루엣(알파 채널)만 남고 배경은 완전히 투명**하다.
  이 앱은 `.renderingMode(.template)`로 알파 채널만 마스크로 쓰고 원래 색(주황)은
  버린 뒤 사용자가 지정한 단계별 색으로 다시 칠한다. 앱 자체의 번들 아이콘으로는
  쓰지 않는다.
- 상표: "Claude"와 Claude 로고는 Anthropic의 상표이며, 이 서비스를 식별하는 용도로만
  쓴다. 이 프로젝트는 Anthropic과 무관한 비공식 도구다(README.md의 "상표" 절 참고).
